# Fire Bite Restaurant Ordering System

## Project Description

Fire Bite is a responsive restaurant ordering system built with ReactJS. The website allows users to browse the menu, add burgers to a shopping cart, view the total price, enter a delivery location, choose Cash on Delivery, and track their order.

## Objectives

- Provide a simple online restaurant ordering experience.
- Allow users to browse available burgers.
- Manage cart items and calculate the order total.
- Display order information and tracking status.
- Create a responsive interface for desktop and mobile devices.

## Features

- Home page
- About page
- Features page
- Contact page
- Burger menu
- Add burgers to the cart
- Remove items from the cart
- Clear the cart
- Calculate the order total
- Enter a delivery location
- Cash on Delivery option
- Generate an order number
- Track order status
- Responsive design
